# Quant-AI

A daily portfolio manager for one investor on Trade Republic.

You enter what you own; the app reviews it against your targets and says in plain
language what to buy, sell, or leave alone. You place the orders in the broker app.

## Install

Requires Python 3.11 or newer.

    ./install.sh        # Windows: install.bat

## Start

    ./start.sh          # Windows: start.bat

## Update

    ./update.sh         # Windows: update.bat

## Where your data lives

Your positions, settings and history live in your per-user data folder (shown in
Settings), never in the repository. Back up with `quant backup`.
