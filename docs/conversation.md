# How the system talks to you

The system speaks on exactly four channels. Nothing else is allowed to interrupt
you. The philosophy: the system watches every day so you do not have to, and
speaks only when speaking is worth a fee and a decision.

From v10.7.1, every piece of advice you see — the briefing Actions table, the
`quant run` printout, the Overview steps, the weekly report, and the Monthly
decision screen — comes from ONE pipeline (`quant/engine/advice.py`) that obeys
the sizing laws. No screen computes its own buy or sell label, so the system can
never contradict itself, and a long-term asset can never be sold by any surface.

## 1. Daily silent monitor (every trading day, 18:45)

Runs the full pipeline: update market data, revalue holdings, recompute scores,
evaluate alert conditions. If no condition fires, it writes its artifacts and
says **nothing** to you. Silence is the default state.

## 2. Friday weekly summary

Five lines, generated by the Friday daily run:

1. open alerts and their status;
2. up to three notable score movements ("Amazon.com: tactical 58 to 64");
3. the regime line ("Market is rising, high confidence. Affects only the
   Active part.");
4. a monitoring-gap note if any days were missed;
5. if all empty: "Nothing urgent this week."

It appears as an in-app block on Overview, is included in the weekly report, and
is pushed to Telegram only if it contains an open alert or a gap note.

## 3. Monthly decision (your main ritual)

Once per month, before the savings plan executes, you enter the budget and
approve the split. This is 90 percent of your interaction with the system. See
the Monthly decision page.

## 4. Alerts (rare, urgent)

When a condition fires, the system pushes immediately and keeps the alert
visible everywhere until you resolve it. Alerts are phrased as actions for the
next trading day, because the broker accepts orders in the evening and executes
them at the next market open:

```
ACTION FOR TOMORROW
  Amazon.com: sell about 75 EUR.
  Place the order tonight or tomorrow; it executes at market open.
  Reason: tactics fell from 71 to 38 in 7 days.
  Fee: 1 EUR sell. Reply in app: done / declined with reason.
```

## When the system is silent

- No alert condition is true.
- The market is closed (weekends).
- Nothing changed since the last run.

Silence is not a failure. It means there is nothing worth a fee and a decision.

## Why level-triggered

The laptop sleeps. Edge-triggered alerts would be missed. Every condition
inspects the current state, so a monitoring gap delays an alert but never loses
it. The exact gap line is: "Monitoring gap: no runs for N days; conditions
evaluated on the latest data."
