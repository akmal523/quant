## H4 hotfix (BEFORE R8) — sentiment scoring path unwired

### Diagnosis (evidence-backed)
- [`fetch_news_items`](quant/data/news.py:76) hardcodes `"scorer": "default"` (lines 90-93); the fetch path never calls the scorer.
- [`load_news`](quant/data/news.py:130) is the ONLY writer of the news cache.
- [`load_news`](quant/ui/render.py:497) render side already gates the word on `scorer == "model"` — no render change.
- Live: fresh cache (2.0 h) still `scorer model 0 / default 30` -> unwired, confirmed.

### Fix spec
1. Add injectable scorer boundary to [`quant/data/news.py`](quant/data/news.py):
   - `load_news(..., scorer=None, scorer_factory=None, score_timeout=10.0)`.
   - `_default_scorer()`: lazy build `FinBERTBatchScorer` only if `transformers`+`torch` importable; return None otherwise; construction failure -> log one line + None.
   - Batch per symbol: `scores = scorer.score_texts(headlines)`; set item `score` + `scorer="model"`.
   - Timeout/callback failure -> all items stay `default`, no word, one log line (honest, P4).
2. Wire the model when available for BOTH on-demand (Explore) and review (`main.py` merge path already calls `load_news`).
3. Tests (recorded-source, D1 style, boundary stub):
   - model stub returning one non-neutral headline -> `scorer: model` + rendered word.
   - model-absent factory -> `default` + no word.
   - timeout/short factory -> `default` + no word + log line.
   - Adapt [`tests/test_h3_6.py`](tests/test_h3_6.py:127) `test_cache_entries_are_scorer_default` to inject a model-absent factory (keeps its intent).
4. One commit `fix(news): wire sentiment scoring with scorer provenance (H4)`.
5. Acceptance: suite green, golden unmoved, version 10.5.2, checkpoint with hash.
6. Manual verify (user): delete cache or wait expiry -> Explore AMZN shows words; doctor `scorer model > 0`.

### Open design tension (flag to user)
Spec says reuse the "existing 10 s timeout" for scoring. FinBERT CPU inference on a batch of headlines can exceed 10 s on first call (model load). Proposal: `score_timeout` default 10.0 s but model construction done once outside the timed block; if trips too often live, raise to 30 s as a config ruling. Not improvised.
