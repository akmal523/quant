## H3-fix — Registry rollback and bounded invariant (RULING R-H3FIX-1)

### Diagnosis (evidence-backed)
- `quant doctor` `registry rows` counts **`asset_registry`** (DuckDB), see [`quant/cli/__init__.py`](quant/cli/__init__.py:85). It is 1090; 1000 rows have empty `display_name` AND empty `name`.
- [`data/broker_registry.csv`](data/broker_registry.csv:1) is already bounded (33 rows) and is user-owned routing input. It is NOT the regressed store.
- `*.duckdb` is gitignored ([`.gitignore`](.gitignore:2)); the rollback therefore is **runtime code**, not a file diff.
- Root cause: [`quant/execution/discovery.py`](quant/execution/discovery.py:217) `run_discovery()` loops over the 1000+ `universe_master` and INSERTs a row per symbol into `asset_registry` on fetch failure (upsert at lines 232-239).
- Existing guard [`tests/test_registry_bounded.py`](tests/test_registry_bounded.py:23) only checks the CSV, so it cannot catch the DB explosion.

### The bound W (recomputed live, never hardcoded)
```
W = funnel survivors (cached)
  ∪ CORE ∪ ACTIVE            (asset_registry.universe_status)
  ∪ portfolio.csv symbols
  ∪ broker_registry.csv symbols
  ∪ symbols with curated ISIN/name entries
```
- Rollback target = exactly `W`. Every row outside `W` is deleted (membership only; inside rows keep all cells).
- Future `universe_master` -> `asset_registry` inserts are legal only via discovery graduation: one symbol at a time, with a universe event.

### Implementation spec
1. **Pure helper** computing `W` from live inputs (funnel survivors cache, asset_registry statuses, [`data/portfolio.csv`](data/portfolio.csv), [`data/broker_registry.csv`](data/broker_registry.csv), curated files).
2. **Runtime self-heal prune**: delete `asset_registry` rows outside `W`; idempotent; logs pruned count to the run log. Invoked in the update path and once at `init_db` for stale local DBs.
3. **Doctor transparency**: line becomes `registry rows: {n} (working universe)`.
4. **Root-cause fix**: remove the bulk `universe_master` -> `asset_registry` insert from [`quant/execution/discovery.py`](quant/execution/discovery.py). Legal entry is graduation only.
5. **Audit**: document the source set of every `asset_registry` writer in code comments + a [`CONTEXT.md`](CONTEXT.md:317) paragraph (already partly present; extend it).
6. **Heal residual cells**: the next update's name/currency backfill covers `W`, returning missing-name counts to zero; missing currency may remain for unreached rows (visible in doctor).

### Guard test — [`tests/test_registry_bounded.py`](tests/test_registry_bounded.py)
- (a) `asset_registry ⊆ W` on a fixture run.
- (b) the bulk-insert path, invoked directly, is a no-op or raises with a logged warning.
- (c) `broker_registry.csv` row count <= |portfolio ∪ CORE ∪ ACTIVE ∪ curated| + small buffer.

### Acceptance
- `quant doctor`: `registry rows: {n} (working universe)` with n == |W| (~90), `missing display_name: 0`, `missing name: 0`.
- Suite green incl. bounded test; golden unmoved; version 10.5.2.
- One or two commits (prune+guard, then root-cause fix if separable).
- Re-run terminal trio (update/run/publish); default output shape still matches the H3.2 contract (<=20 lines each).
